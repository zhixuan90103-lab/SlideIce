# 舞台

当前画面。玩法以 [GAME.md](GAME.md) 为准。改画面以本文为准。

## 模块

| 模块 | 职责 |
|------|------|
| `src/game/level.ts` | 这一关的占格和颜色。 |
| `src/game/look.ts` | 光、相机、块尺寸的默认值。设置面板改的就是这一份。 |
| `src/game/stage.ts` | 天空、光、阴影、底板、格子、左/右/下三面墙、六块挤出体。上面敞开。 |
| `src/game/play.ts` | 拖动、阻挡、松手脱离。入口是 `mountSlideGame`。 |
| `src/game/hint.ts` | 松手就会脱离时的发亮。不挡操作。 |
| `src/game/shatter.ts` | 离场碎块。不挡操作。 |
| `src/game/praise.ts` | 离场文字。只往上飘。不挡操作。 |
| `src/main.ts` | 启动、透视相机、设置按钮。 |

世界坐标：x 向右，y 向上（等于设计坐标的 −y），z 朝向镜头。棋盘中心在设计画面中心。

## 画面

- 天空是竖向渐变：`#4aa8ee` → `#79c6f8` → `#9ed8fb`。
- 曝光 1.1。环境贴图强度 0。
- 半球光强度 1.55，天空 `#fff8f2`，地面 `#f3d7be`。设置里的「环境」调的是这盏光。单独的环境光和轮廓光强度为 0。
- 主光白，强度 0.85，方位 −30°，仰角 80°。辅光 `#ffe4cc`，强度 0.28，方位 −101°，仰角 57°。方位 0° 从画面上方来，正值偏向 +x。仰角 0° 贴地，90° 从 +z 来。
- 阴影是软阴影，贴图 2048，半径 6，bias −0.0008，normalBias 0.04。背景色不接阴影。`ShadowMaterial` 比画面每边多出 400，不透明度 0.4，放在 z = −40。阴影相机各向 900，块挪出屏幕一段后影子仍完整。底板会投影到这张面上。
- 透视相机。俯仰 −15°，偏航 0°。视野固定为距离 1200 时刚好包住 844 设计高的那一档。镜头距离按底板外沿缩放，使底板两侧留白与 5×5、块边长 60 时相同。5×5 默认距离 1200。设置里改「块」会重算距离；改「距离」则在这个视野上手动缩放。

设置按钮在 `#ui-root` 里，默认收起。面板里是上面这些光和相机，加上块尺寸、圆角、棱、粗糙度。

## 棋盘

底板和墙同一材质 `#faf7f3`，粗糙度 0.62，金属度 0。格子是单独一块平面，铺在画面中心，尺寸就是 5×5 格（320×320）。格 64、缝 4。格内 `#faf7f3`，缝 `#f3efe9`。底板或墙变大时格子不拉伸，缝保持 4。

外沿按方块边长重算。下面公式里的棋盘边长是 320，边距 4，墙厚 12，墙的平面倒角 5：

```
opening = 320 − (64 − size) + 8
hole    = opening + 10
outer   = hole + 24
```

`opening` 是块能活动的内口。碰撞用这个矩形的左、右、下三条边，上边不挡。可见外沿等于 `outer` 再加两侧倒角 5。

### 墙

一面墙，左、右、下三面，厚 12，上方敞开。和底板同中心。

- 下方两个外角与底板同圆心。路径半径是 `max(圆角, 棱) + 4 + 5 + 12`。内角半径少 12，弯过去厚度不变。
- 上方出口是平头。两端圆角半径是 `min(圆角, 12 / 2 − 2)`，默认圆角 5 时为 4。头顶留出直边。
- 直壁深度是方块边长减 6。底倒角厚 6，埋进底板，墙底在 z = −7。
- 轮廓逆时针。挤出倒角在上下两端，平面倒角 5，倒角分段 4，弧分段 12。

### 底板

厚 24，顶面在 z = −7，会投影。四角都是圆角，路径半径等于墙的外角路径半径再加墙的平面倒角 5、减去底板自己的倒角 2。底板倒角尺寸是 2。路径边长先按可见外沿扣掉这 2，再挤出。可见半径等于路径半径加 2，与墙的外角对齐。

## 方块

六块铺满 5×5，占格和颜色见 [GAME.md](GAME.md) §4。粗糙度 0.42，金属度 0.02，环境贴图强度 0。同一块内部不留缝，块与块之间的缝是 4。凸角按圆角倒，凹角保持尖。

每块是一条逆时针轮廓的 `ExtrudeGeometry`。默认边长 60，圆角 5，棱 8。底面贴在 z = −7。倒角在上下两端，厚度是棱。轮廓先内收一个棱，挤出后再胀回边长。

设置里的「块 / 圆角 / 棱」同时改全部方块、底板和墙。外沿、墙角、出口圆角都按上面的公式重算。
