# 舞台

当前画面的造型规范。玩法仍以 [GAME.md](GAME.md) 为准：5×5、格 64、缝 4、一种出口方向。命中仍按设计格，不用射线。

这一关现在画的是造型台，不是 §5 那组木块。改画面以本文为准。`GAME.md` §4 里的正交相机、斜切和木纹是旧外形，当前画面不用。

## 模块

| 模块 | 职责 |
|------|------|
| `src/game/look.ts` | 画面默认值。设置面板改的就是这一份。 |
| `src/game/stage.ts` | 天空、光、阴影面、底板、格子、墙、25 个方块。 |
| `src/game/play.ts` | 规则、拖动、棋子网格。不搭建现在这套造型。 |
| `src/main.ts` | 启动、透视相机、设置按钮。 |

世界坐标：x 向右，y 向上（等于设计坐标的 −y），z 朝向镜头。棋盘中心在设计画面中心。

## 画面

- 天空是竖向渐变：`#4aa8ee` → `#79c6f8` → `#9ed8fb`。
- 曝光 1.1。环境贴图强度 0。
- 半球光强度 1.55，天空 `#fff8f2`，地面 `#f3d7be`。设置里的「环境」调的是这盏光。单独的环境光和轮廓光强度为 0。
- 主光白，强度 0.85，方位 −30°，仰角 80°。辅光 `#ffe4cc`，强度 0.28，方位 −101°，仰角 57°。方位 0° 从画面上方来，正值偏向 +x。仰角 0° 贴地，90° 从 +z 来。
- 阴影是软阴影，贴图 2048，半径 6，bias −0.0008，normalBias 0.04。背景色不接阴影。一块铺满 390×844 的 `ShadowMaterial` 接收影子，不透明度 0.4，放在 z = −40。
- 透视相机。俯仰 −15°，偏航 0°，距离 1200。视野按距离把 844 的设计高包进画面。

设置按钮在 `#ui-root` 里，默认收起。面板里是上面这些光和相机，加上块尺寸、圆角、棱、粗糙度。

## 棋盘

底板和墙同一材质：`#faf7f3`，粗糙度 0.62，金属度 0。

格子是单独一块平面，铺在底板中心，尺寸就是 5×5 格（320×320）。格 64、缝 4。格内 `#faf7f3`，缝 `#f3efe9`。底板变大时格子不拉伸，缝保持 4。

墙目前只显示左侧一条。厚度按 12 设计，直壁深度是方块边长减 6，底倒角 6 埋进底板（墙的 z = 底板顶 −7 再加 6）。挤出倒角厚度 6、倒角尺寸 5。倒角把直壁向外胀，可见厚度大于 12。不要为了贴合可见厚度去改 12 和 6。

外沿按方块边长重算，方块外沿到内壁按 4 设计：

```
opening = 320 − (64 − size) + 8
hole    = opening + 10
outer   = hole + 24
```

左墙路径宽 12、长 `outer`，贴在 `outer` 的左侧。两端圆角不超过 6。

底板厚 24，顶面在 z = −7，不投影。可见边长等于左墙可见长度（路径长 `outer` 再加两侧倒角 5）。底板自己的倒角尺寸是 2，路径边长要先扣掉这 2。四角的可见圆角与四面墙外角一致：墙外角路径半径是 `max(圆角, 棱) + 4 + 5 + 12`，可见半径再加墙倒角 5；底板路径半径等于这个可见半径减去 2。四面墙可以藏起来，底面圆角仍按这个外角留着。

## 方块

每格中心一块，共 25 块。颜色 `#f27b4e`，粗糙度 0.42，金属度 0.02，环境贴图强度 0。

默认边长 60，圆角 5，棱 8。底面贴在 z = −7。顶面是 12×12 的均匀网格，棱用 24 段圆弧。

设置里的「块 / 圆角 / 棱」同时改全部方块，并让墙和底板按上面的外沿重算。
