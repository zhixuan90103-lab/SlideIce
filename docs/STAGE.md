# 舞台

当前画面是第一关规则之外的造型台。玩法仍以 [GAME.md](GAME.md) 为准：5×5、格 64、缝 4、一种出口方向。这里只规定现在画面上已经定下来的东西。

## 模块

| 模块 | 职责 |
|------|------|
| `src/game/look.ts` | 画面默认值。设置面板改的就是这一份。 |
| `src/game/stage.ts` | 天空、光、阴影面、底板、格子、墙、25 个方块。 |
| `src/game/play.ts` | 规则、拖动、棋子。不负责现在这套造型。 |
| `src/main.ts` | 启动、透视相机、设置按钮。 |

世界坐标不变：x 向右，y 向上（等于设计坐标的 −y），z 朝向镜头。

## 画面

- 天空是竖向渐变：`#4aa8ee` → `#79c6f8` → `#9ed8fb`。
- 曝光 1.1。环境贴图强度 0。
- 半球光强度 1.55，天空 `#fff8f2`，地面 `#f3d7be`。设置里的「环境」调的是这盏光。单独的环境光和轮廓光强度为 0。
- 主光白，强度 0.85，方位 −30°，仰角 80°。辅光 `#ffe4cc`，强度 0.28，方位 −101°，仰角 57°。
- 阴影是软阴影，贴图 2048，半径 6。背景上的影子由一块铺满设计画面的 `ShadowMaterial` 接收，不透明度 0.4，放在 z = −40。
- 相机俯仰 −15°，偏航 0°，距离 1200。

## 棋盘

- 底板和墙用同一材质：`#faf7f3`，粗糙度 0.62，金属度 0。
- 底板厚 24，顶面在 z = −7。
- 格子是 5×5，按格 64、缝 4 画在底板上。缝的颜色是 `#f3efe9`。
- 墙是一圈带倒角的框。直壁高度跟方块走，底倒角埋进底板。墙厚按 12 设计，方块外沿到内壁按 4 设计。倒角会把直壁向外胀，所以现在的可见宽度大于 12。这是当前造型，重构不改它。

## 方块

- 每格中心一块，共 25 块。颜色 `#f27b4e`，粗糙度 0.42，金属度 0.02。
- 默认尺寸 60，圆角 5，棱 8。顶面是 12×12 的均匀网格，棱用 24 段圆弧。
- 设置里的「块 / 圆角 / 棱」同时改全部方块，并让墙和底板跟着外沿重算。
