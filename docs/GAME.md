# 滑块

配套：[AGENTS.md](../AGENTS.md) · [STAGE.md](./STAGE.md)

当前玩法。关卡占格和棋盘边长在 `src/game/level.ts` 的 `GRID`。指针和落格队列在 `play.ts`。锁轴、碰撞和松手计划在 `slide.ts`。格子、越边和轮廓在 `stage.ts`。落格晃动在 `rock.ts`。描边在 `stage.ts`。发亮在 `hint.ts`，碎块在 `shatter.ts`，文字在 `praise.ts`。四下短震的时机和参数在 `hapticFeel.ts`，见 §2.4。画面在 [STAGE.md](STAGE.md)。同一问题只问一处，见 §5。

格子：列向右，行向下，左上是 `(0,0)`。世界坐标 `x = 设计 x`，`y = −设计 y`。下是世界 −y，左是世界 −x。

## 0. 操作优先

玩家操作的反馈是第一优先级。动画、碎块、文字、发亮都不能挡住下一次按下、拖动或松手。播放中的动画可以被新的操作打断。操作不排队等动画结束。

## 1. 规则

棋盘边长是 `level.ts` 的 `GRID`，格距 64。画面、占格和相机距离都读这一份，不另写一个 5。当前 `GRID` 是 5。六块铺满，没有空格，也没有固定阻挡。每块同一套规则，不预设离开方向。

块和块不能重叠、不能穿过。哪边走得通由当时的形状决定。

过关：全部块都脱离。没有步数、时间、生命。这一关不接音效。震动见 §2.4。清空后停止输入，不放结算按钮。

## 2. 操作

听 `#stage` 的指针，并捕获这只指针。第二只手指还按着时不开始新手势。设计坐标只走 `clientToDesign`，用 `#stage` 的边框除以舞台缩放，不再减一次布局偏移。按下时点要在舞台内，可以落在空白上。抓住之后手指滑出舞台，位移照常计算。`pointerup`、`pointercancel` 和丢失捕获都松手。

上一笔的捕获已经不在时，新的按下先松开上一块，再拿起这一块。避免滑出棋盘后立刻点下一块时，松手事件没到，下一笔被丢掉。

命中按块的占格，不用射线。相机不跟着块动。距离都用设计坐标，不看设备像素。

| 量 | 值 | 用在 |
|----|-----|------|
| 死区 | 8 | 第一次锁轴前，块不动 |
| 锁轴比 | 1.5 | 一轴达到另一轴的这倍才锁 |
| 趋势长度 | 16 | 换轴看最近这一段 |
| 换轴死区 | 4 | 另一轴至少走这么远才算转了 |
| 归位带 | 32（半格） | 块离按下姿态在这以内才允许换轴 |
| 快滑 | 900 设计像素/秒，窗口 0.08 秒，只算锁轴分量 | 松手后沿轴滑出 |
| 落格 | 900 设计像素/秒 | 回到最近可落格 |
| 落格晃动 | 满一格 6°，0.2 秒 | 见 §2.3 |

### 按下

落在块上时，当帧选中：块抬起，描边出现，锚点不动。落在空白上不选中。按下时块立刻抬起约自身厚度的一半。松手后抬起再缓落，同时缓动到落点。描边见 §2.1。

### 锁轴

手指离按下点不足 8 个设计像素时不锁轴，块不动。超出之后，一轴的位移达到另一轴的 1.5 倍才锁这根轴。还在斜向时，按下那块继续只显示选中，不位移。

### 换轴

手指轨迹只有 `rememberFinger` 一条缓冲。更早的点要丢掉时，最近 0.08 秒和最近 16 个设计像素都必须还留在缓冲里。换轴看这 16 像素里的趋势，不另做一套采样。原来那根轴仍然更长，轴保持。另一根已经更长并且超过 4 个设计像素，趋势转了。这时只有块回到按下姿态的半格（32 个设计像素）以内，或者旧方向已经贴住并且这一小段顺着接触面，才换轴。换轴当帧块停在当前姿态，这一小段之前的横向距离不加到块上。松手时轴还没锁上，就没有滑动方向，落到最近的可落格。中途接住的块，用接住时的姿态当这个原位。

### 跟手

轴锁上之后，当前块沿这根轴跟手。从空白滑上去的块，从接住那一帧的位置起算，不再减死区。按下就选中的块，仍从按下位置起算并减掉这 8 像素。另一轴保持接住时的位置。会不会撞上、停在多远、正前方是谁，都只问 `slide.ts` 的 `sweep`。撞到别的块停在第一次接触，不穿过去。贴住时不晃，见 §2.2。

### 换块

分两段。手指还在当前块上时，只有已经碰到正前方那块才换，旁边擦到的不换。手指已经不在当前块上、并且落在另一块上时，换成手指下的那块；绿块还选着、手指已经完全到了紫块上，就取消绿块并选中紫块。多块同时被压住时，取趋势方向上更靠前的一块。正在落格的块都不会被重新选中。一次手势里可以同时有多块在落格，后丢掉的不盖掉先丢掉的。手指不在任何块上时，还在推力那一侧就继续抓着，退到块背后再落格。没撞上、也没换块时不退出。只有松手时还选着的那块才走消除、滑出或回格。

### 松手

没有墙。块只被别的块挡住。四个方向都能离开当前关卡的棋盘。按住期间不消除，可以停在半出界的位置。松手只有三种结果。

1. 沿最后认过的那根轴已经越出棋盘，离最近的可落格至少有一格，并且这根轴的出口能走完：立刻消除。另一条边是空的不算。轴还没锁上时不走这一条。
2. 还在棋盘里，并且松手时最近 0.08 秒在这根轴上的分量仍够 900 设计像素/秒：沿这根轴，按这个分量滑到出界再消除。斜向手指的另一轴不计入速度。中途会碰到别的块，就按这个速度停在接触处，再落到棋盘内的整格。
3. 其余情况，包括慢拖和不够一格的挪动，都回到最近的可落格。落下时放平，到达后的晃动见 §2.3。

一样近时先取更小的列偏移，再取更小的行偏移。下一次按下打断当时所有的落格和滑出，这些块停在播到的位置，并放平。发亮只在松手会消除时出现。快滑粒子等参考来了再加。

拖动中，松手就会消除的那块一直发亮。本色不动，按自己的颜色加 0.22 的自发光，并放大到 1.02。大约 0.08 秒淡入淡出。拖回来就灭。

## 2.1 拿起描边

描边挂在块上，只在抬起时可见，透明度跟抬起值走。形状是外形向外 4 个设计像素的棱柱，只画背面，所以看见的是外轮廓，不是腰上的一圈。颜色是这块自己的颜色，亮度提高（明度加 0.34，上限 0.92）。

描边画在所有块之后，并且只拿自己这块的深度做遮挡。遮罩用一份固定的只写深度的材质，不改块自己的材质。描边略偏向相机，避免和块的侧面抢同一深度。经过别的块时盖在上面，不切进别的块里。不投影，不接阴影。

## 2.2 撞上

撞到角或边时块停在接触处。不播抖动，也不改锚点。

## 2.3 落格

块飞向格子时保持放平，锚点按每秒 900 设计像素走到落点。

锚点到达格子之后晃一次，沿松手时认过的滑动方向。向上滑时下边低，向右滑时左边低。幅度按松手时锚点到落点的距离比上一格：满一格是 6°，更远仍是 6°，更近按比例缩小。没有滑动方向，或这段距离是 0，不晃。

晃动 0.2 秒，一个来回，幅度随时间衰减到放平。只转块本身，锚点留在格子上，并抬高到低边贴住棋盘。消除和滑出棋盘不晃。新的按下放平并打断。

## 2.4 震动

四下都是一次短震，只走 `hapticFeel.ts` 的 `pulseHaptic`。浏览器没有插件时走 `navigator.vibrate`，没有强度差别。真机才用下表的强度和锐度。按住同一处接触不连震。发亮灭了再亮才再震一次。插件怎么注册见 [HAPTICS.md](./HAPTICS.md)，页面上没有单独的震动按钮。

| 时机 | 强度 | 锐度 |
|------|------|------|
| 拿起一块 | 0.3 | 0.3 |
| 刚撞上别的块 | 0.3 | 1 |
| 发亮开始 | 0.25 | 0.3 |
| 块离开棋盘 | 0.45 | 0.33 |

## 3. 离场

脱离的块立刻换成一堆圆角小块，铺在它松手时的外形上。每格 6 个，3 列 2 行，落在格子正中。小块边长 21，厚 18.6，倒角 3.4。每块再乘 0.78 到 0.92 的随机缩放。颜色和粗糙度跟离开的那块相同。小块从中心向外散开，再落下、缩小，掉出画面下沿后消失。不挡还在盘上的块，也不投影。

文字和连消同一套。单独离开的第一块不写字。之后依次是 Great!、Perfect、Excellent!、Amazing。一次离开多块会跳一档，这一关每次只离开一块。字尽量出现在块中心上方 56 像素。顶到画面上沿就改到块下面，但一律往上飘，然后淡出。

## 5. 同一问题一个入口

玩法和画面不要为同一件事再写一个函数。新代码调用下表这一处。

| 问题 | 只问 |
|------|------|
| 会不会撞上、停在多远、正前方是谁 | `slide.ts` 的 `sweep` |
| 这个点在哪一格、姿态是否整格都在盘上、越出的是哪条边、沿这条边还要滑多远 | `stage.ts` 的 `cellOf`、`poseOnBoard`、`crossesEdge`、`exitDistance` |
| 块身内收、描边外扩 | `stage.ts` 的 `offsetClosed` |
| 手指轨迹、锁轴速度、换轴趋势 | `rememberFinger` 一条缓冲。速度是最近 0.08 秒里锁轴方向的分量。趋势是最近 16 个设计像素 |
| 棋盘有几格 | `level.ts` 的 `GRID` |
| 屏幕上的点换成设计坐标 | `clientToDesign`，参数是 `#stage` 的边框和缩放 |
| 一块正在飞向格子 | `play.ts` 的落格列表。一块一条，按下时整表打断 |
| 拿起、撞上、发亮、离场的震动 | `hapticFeel.ts` 的 `pulseHaptic`。不要在玩法里再调一次 `playTransient` |
