# 滑块

配套：[AGENTS.md](../AGENTS.md) · [STAGE.md](./STAGE.md)

当前玩法。关卡数据在 `src/game/level.ts`，操作在 `src/game/play.ts`，离场反馈在 `shatter.ts` 和 `praise.ts`。画面在 [STAGE.md](STAGE.md)。

格子：列向右，行向下，左上是 `(0,0)`。世界坐标 `x = 设计 x`，`y = −设计 y`。

## 1. 规则

5×5，格距 64。六块铺满，没有空格，也没有固定阻挡。每块同一套规则，不预设离开方向。

块和块不能重叠、不能穿过。哪边走得通由当时的形状决定。

过关：全部块都脱离。没有步数、时间、生命。这一关不接音效和震动。清空后停止输入，不放结算按钮。

## 2. 操作

听 `#stage` 的指针，并捕获这只指针。第二只手指不开始新手势。设计坐标用舞台矩形换算。按下时点要在舞台内并且点在块上。抓住之后手指滑出舞台，位移照常计算。`pointerup` 和 `pointercancel` 都松手。

- 按住块身上的点，这个点跟着手指连续走，块不跳到中心。按住时块抬起约自身厚度的一半，松手落回底板。
- 斜着拖时比较这一下水平和垂直哪个更大。朝挡住的一侧更大就停住。卡住时挤多少、弹不弹，以后再定。朝空着的一侧更大，就沿那边走到分开，再继续跟手。
- 被挡住时手指可以继续往前，块留在接触处，不追过去。之后往走得通的方向移，块从停下的位置直接跟上。跟手的松紧以后再调。
- 格子边不挡路。按住期间中心出了格子也不脱离。松手时看这块自己的中心：还在 5×5 里就留在当时的位置；已经出格就脱离。

命中按块的占格，不用射线。相机不跟着块动。

## 3. 离场

脱离的块立刻换成一堆圆角小块，铺在它松手时的外形上。小块从中心向外散开，再落下、缩小，掉出画面下沿后消失。不挡还在盘上的块，也不投影。

文字和连消同一套。单独离开的第一块不写字。之后依次是 Great!、Perfect、Excellent!、Amazing。一次离开多块会跳一档，这一关每次只离开一块。字尽量出现在块中心上方 56 像素。顶到画面上沿就改到块下面，但一律往上飘，然后淡出。
