# 滑块

配套：[AGENTS.md](../AGENTS.md) · [STAGE.md](./STAGE.md)

当前玩法。关卡在 `src/game/level.ts`。指针、跟手和离场在 `play.ts` 与 `slide.ts`。描边在 `stage.ts`。发亮在 `hint.ts`，碎块在 `shatter.ts`，文字在 `praise.ts`。画面在 [STAGE.md](STAGE.md)。

格子：列向右，行向下，左上是 `(0,0)`。世界坐标 `x = 设计 x`，`y = −设计 y`。

## 0. 操作优先

玩家操作的反馈是第一优先级。动画、碎块、文字、发亮都不能挡住下一次按下、拖动或松手。播放中的动画可以被新的操作打断。操作不排队等动画结束。

## 1. 规则

这一关是 5×5，格距 64。棋盘大小跟着关卡走，不是永远 5×5。六块铺满，没有空格，也没有固定阻挡。每块同一套规则，不预设离开方向。

块和块不能重叠、不能穿过。哪边走得通由当时的形状决定。

过关：全部块都脱离。没有步数、时间、生命。这一关不接音效和震动。清空后停止输入，不放结算按钮。

## 2. 操作

听 `#stage` 的指针，并捕获这只指针。第二只手指还按着时不开始新手势。设计坐标用舞台矩形换算。按下时点要在舞台内并且点在块上。抓住之后手指滑出舞台，位移照常计算。`pointerup`、`pointercancel` 和丢失捕获都松手。

上一笔的捕获已经不在时，新的按下先松开上一块，再拿起这一块。避免滑出棋盘后立刻点下一块时，松手事件没到，下一笔被丢掉。

- 按住块身上的点，按下时记下抓住点（手指相对块锚点的偏移）。块不跳到中心。慢滑时块走在手指采样点连成的折线上：相邻两点之间按时间线性插值。跟随点比最新的采样晚约 0.02 秒，这段走完就落在最新的点上。
- 慢滑两轴都走，不锁轴，不吸格。挡住的轴停在第一次接触，不穿块。通开的轴补到折线上的跟随点。
- 快滑认一块、认一轴，只在还快着的时候沿这根轴走。最近约 0.08 秒、并且这段至少有 0.05 秒时，速度达到每秒 900 像素才算快滑。这个速度下从按下算起要有 28 像素；更快时需要的距离按速度反比下降，最少 8 像素。速度和长度都看手指的原始采样。轴只看这最近一小段。朝某个能整块离开棋盘的方向的分量达到这一小段长度的 0.6，就沿那个解锁方向走，否则沿这一小段更长的轴。被围住的块没有解锁方向。锁住的轴保持抓住点，贴着手指。另一轴先把抓住点拨到块的当前位置，再算这一帧，这段横移不入账。换轴或慢下来之后沿拨过的抓住点只吃新的移动。慢下来就回到两轴跟手。这些数是手机上的起点，还要再对。
- 撞上角或边只停住，不播抖动。快滑粒子等参考来了再加。
- 没有墙。块只被别的块挡住。四个方向都能离开当前关卡的棋盘。按住期间不消除，可以停在半出界的位置。松手只有三种结果。已经越出棋盘、离最近的可落格至少有一格、并且出口能走完：立刻消除。还在棋盘里、并且松手时最近这一小段仍够快：沿这一滑最后认过的那根轴，按这一小段的速度滑到出界再消除；中途会碰到别的块，就按这个速度停在接触处，再落到棋盘内的整格。其余情况，包括慢拖和不够一格的挪动，都回到最近的可落格。发亮只在松手会消除时出现。一样近时先取更小的列偏移，再取更小的行偏移。下一次按下打断落格和滑出，块停在播到的位置。
- 按下时块立刻抬起约自身厚度的一半，描边同时出现。松手后抬起再缓落，同时缓动到落点。
- 拖动中，松手就会消除的那块一直发亮。本色不动，按自己的颜色加 0.22 的自发光，并放大到 1.02。大约 0.08 秒淡入淡出。拖回来就灭。

命中按块的占格，不用射线。相机不跟着块动。

## 2.1 拿起描边

描边挂在块上，只在抬起时可见，透明度跟抬起值走。形状是外形向外 4 个设计像素的棱柱，只画背面，所以看见的是外轮廓，不是腰上的一圈。颜色是这块自己的颜色，亮度提高（明度加 0.34，上限 0.92）。

描边画在所有块之后，并且只拿自己这块的深度做遮挡。遮罩用一份固定的只写深度的材质，不改块自己的材质。描边略偏向相机，避免和块的侧面抢同一深度。经过别的块时盖在上面，不切进别的块里。不投影，不接阴影。

## 2.2 撞上

撞到角或边时块停在接触处。不播抖动，也不改锚点。

## 3. 离场

脱离的块立刻换成一堆圆角小块，铺在它松手时的外形上。小块从中心向外散开，再落下、缩小，掉出画面下沿后消失。不挡还在盘上的块，也不投影。

文字和连消同一套。单独离开的第一块不写字。之后依次是 Great!、Perfect、Excellent!、Amazing。一次离开多块会跳一档，这一关每次只离开一块。字尽量出现在块中心上方 56 像素。顶到画面上沿就改到块下面，但一律往上飘，然后淡出。

## 4. 这一关

```
红 红 红 蓝 蓝
红 绿 绿 绿 蓝
黄 黄 绿 粉 蓝
黄 紫 紫 粉 粉
黄 黄 紫 紫 粉
```

| 块 | 格（列, 行） | 颜色 |
|----|----------------|------|
| 红 | (0,0) (1,0) (2,0) (0,1) | `#fa005b` |
| 蓝 | (3,0) (4,0) (4,1) (4,2) | `#0087fa` |
| 绿 | (1,1) (2,1) (3,1) (2,2) | `#00fa5b` |
| 黄 | (0,2) (1,2) (0,3) (0,4) (1,4) | `#fab500` |
| 紫 | (1,3) (2,3) (2,4) (3,4) | `#c000fa` |
| 粉 | (3,2) (3,3) (4,3) (4,4) | `#fa2000` |

黄色是 `#fab500`。红、绿、紫、粉用同一组饱和度 1、明度 0.49，只以色相区分。蓝色单独指定为 `#0087fa`。
