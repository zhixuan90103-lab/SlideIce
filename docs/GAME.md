# 冰块救人

配套：[AGENTS.md](../AGENTS.md) · [ENGINEERING.md](./ENGINEERING.md)

底座仍是竖屏 WebGPU，设计空间 **390×844**。这篇是玩法方案。依据笔记本「冰块救人」里的三篇：世界观与设定、玩法规则、市场调研。

## 1. 项目

水中救援解谜。玩家看见一整片水和浮在上面的冰，看不见格子。一整关是一个大谜题，由互相牵制的冰块组成。

玩家只做一件事：从许多块冰里选出当前该动的一块，沿它身体标出的缝滑开。冰不再盖住的人立刻获救。冰还留在画面里，就继续挡住别的冰。所有人都获救，并且所有冰都滑出画面，这一关才清除。

## 2. 一局

先按住一块冰，沿缝拖，只选定方向。松手把这一滑交出去。没有倒计时，也没有按住多久才触发。

缝通了，整块自己滑出画面，不能再推回来。缝上有东西，整块停在挡住的地方。还在画面里的冰，下一次仍沿同一条缝滑，包括滑回去。滑回去只改变冰的位置，不能把已经获救的人再盖住。

## 3. 规则

方向看身体，不另画箭头。宽大于高只左右，高大于宽只上下。宽和高一样而且铺满，四向都能滑：1×1、2×2、铺满的 3×3。同一块冰不旋转。横条和竖条是两块冰。

能进关卡的形状：两格、三格、四格长条；外框 3×2 的 T、四格 L、S，沿长边走，短出来的一截只挡旁边。三格 L、十、五格 T 和 V、外框 3×3 又不铺满的大土不进关卡。眼睛只能读出一个方向。

一块冰按格子占位。这些格子边靠边连成一个身体，整块一起滑。同一个形状不能拆成多块冰。

任意两块冰不能盖住同一格。关卡开始时不重叠，滑动之后也不重叠。

宽的冰整块平移。要滑的那一排每一格都得空，只空一格就停下。凸出来的一截扫过的格子也必须空着。旁边空着，不开新路。

人占冰下的一格。这一格在关卡里定死，这一局不改。长条一个人，在这条缝上。T、四格 L、S 两个人：一个在长缝上，一个在凸出来的那一截上。铺满方块按边长：1×1 一个，2×2 两个，3×3 三个。冰不再盖住这一格，这个人立刻获救。先露出的人先获救。玩家看见的是冰下的人，不是格子。

岸在相对的两边，按关卡设置，不改缝的方向。上下是岸，只有左右能滑出画面。左右是岸，只有上下能滑出画面。只朝岸滑的冰不进这一关。铺满方块可以进：朝岸滑到边就停下，朝河才能滑出画面。

## 4. 画面

方地是一片水面。冰浮在水上。人在冰的正下方，高度上被这块冰盖住，隔着冰能看见。人不站在冰的侧面，也不夹在两块冰的缝里。

一块冰画成一整块。占几格，外形就按这几格长出来，中间不再切开。两格是一块，三格、四格、方块、T、L、S 也各是一块。格子大小全场一样。玩家看不见格子线。

开局冰与冰之间留出水。不边靠边挤满，也不重叠。

岸相对平。不画大浪。上下岸或左右岸按这一关的设置。

冰滑出时整块继续在水上滑，漂出画面，不碎、不化、不转。画面不跟着冰走。人获救之后游向岸，只是动画，不算新的一步。玩家没有第二个动作。动画不占格子，也不挡缝。

样子是偏亮的天蓝、圆角、哑光的软三维。人不写实，造型简单，可以带一点珊瑚、黄、绿。不做成大头幼态。画面上不放倒计时、金币、心、奖励按钮。

效果图用竖屏 9:19.5，按 iPhone 15 Pro 的比例看。游戏里的设计空间仍是 390×844，不随效果图改。

## 5. 不做

不加颜色门、上车、额外空位、道具，不加第二个动词，不加第二层。不加倒计时，不加生命。人不因等待而死。不把「看广告，否则这关做不完」写进规则。呼救不定顺序。

单轴滑动、每辆车都开出去、同色门清盘，市场上已有成品。四件一起没找到：按身体定方向、画面里能推回、让开就救人、人和冰都清完才过关。

## 6. 落在底座上

玩法放在 `src/game/`。UI 只挂 `#ui-root`。棋盘按设计空间排在舞台里，不跟窗口像素走。触控用 `clientToDesign`，letterbox 外的点丢掉。逻辑格子不画出来。

一关的数据写明：岸在上下还是左右；每块冰的形状、位置和方向；每个人在哪一格。形状和人数先按本文检查，不合格的关卡不进包。

先做能玩的一关：选冰、松手、滑或停、让开就救人、滑出不再回来、人和冰都清完才过关。岸和漂出画面跟着这一关做完。震动和音效不进这一步。
